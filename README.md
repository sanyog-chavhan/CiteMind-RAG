# CiteMind

A Streamlit app that answers questions about a research paper and cites the passages it retrieved. Retrieval uses ChromaDB with FastEmbed embeddings, and answers are generated by Claude.

**Live demo:** https://cite-mind-rag.streamlit.app

**Source document:** Pedro Domingos, "A Few Useful Things to Know about Machine Learning," *Communications of the ACM*, 2012.
https://homes.cs.washington.edu/~pedrod/papers/cacm12.pdf

## Setup

Requirements: Python 3.14 (tested) and an Anthropic API key.

```bash
git clone https://github.com/<sanyog-chavhan>/citemind-rag.git
cd citemind-rag
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

Create a `.env` file in the project root:

```
ANTHROPIC_API_KEY=your-key-here
```

## Build the index

```bash
./venv/bin/python ingest.py
```

This downloads the paper into `papers/` and builds the vector store in `chroma_db/`. Both folders are generated and are not committed to git.

## Run

Ask from the terminal:

```bash
./venv/bin/python rag.py
```

Run the web app:

```bash
./venv/bin/streamlit run app.py
```

## Project layout

- `config.py`: settings, source URL, model names
- `ingest.py`: download, chunk and index the paper
- `vector_store.py`: ChromaDB setup and embedding function
- `rag.py`: retrieval and the Claude call
- `app.py`: Streamlit interface
